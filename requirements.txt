# ai-canvas 后端依赖
#
# 【零依赖】
#
# 这个文件故意是空的（只有注释）。
#
# 最初用官方 oss2 上传到 OSS，但它的依赖链里有 C 扩展（crcmod、pycryptodome），
# 导致一个很实际的问题：
#
#     在 Windows 上打不出能跑在 Linux 函数计算上的包
#     → 配「层」又要另做一套构建流程
#     → 本地能跑不代表传上去能跑（最该避免的情况）
#
# 而我们只用到 OSS 的两个操作：上传对象、查 Bucket 信息。
# 签名就是 HMAC-SHA1 + Base64，标准库全都有。所以改成自己实现
# （见 oss_client.py），把这唯一的第三方依赖也去掉了。
#
# 结果：整个后端只用 Python 标准库。
#      部署的 zip 传到哪都能直接跑，不需要 pip install，不需要配层。
#
# 如果以后要加依赖，写在这，并在部署时用函数计算的「层」提供。
